## 摘要
扩散变换器（DiTs）已成为高保真视频生成的主流范式，但其执行高层语义规划的能力仍然有限。尽管将多模态大语言模型（MLLMs）与扩散主干网络相结合的混合架构在图像合成中显示出显著优势，但在视频生成中此类设计仍未得到充分探索，现有方法通常将MLLMs主要视为冻结的特征编码器，而非语义生成器。为了填补这一空白，我们系统性地研究在视频生成中如何将MLLM与DiT集成，回答三个问题：应当使用什么中间表示来连接MLLM和DiT，MLLM应当如何生成该表示，以及DiT在扩散渲染期间应当如何整合该表示。我们的分析揭示了三个关键发现：（1）基于EMA的分词器产生的离散语义视觉标记提供了稳定且富有表现力的接口；（2）自回归因果建模可有效生成这些标记；（3）显式的视觉标记条件化比提示词优化或潜在空间桥接更有效。基于这些发现，我们提出了BiVidGen，这是一个混合框架，其中MLLM首先生成语义视觉标记，然后DiT通过多层交叉注意力，在文本和这些标记的条件下渲染视频。大量实验表明，与微调的DiT基线相比，BiVidGen提高了语义对齐和时间一致性，在VBench-Long上取得了更强的性能。这些结果表明，基于MLLM的显式视觉规划为文本到视频生成提供了一种超越纯文本条件的有效中间接口。

## Abstract
Diffusion Transformers (DiTs) have become the dominant paradigm for high-fidelity video generation, yet their ability to perform high-level semantic planning remains limited. While hybrid architectures integrating MLLMs with diffusion backbones have shown strong advantages in image synthesis, such designs remain underexplored in video generation, where existing approaches often treat MLLMs primarily as frozen feature encoders rather than semantic generators. To fill this gap, we systematically study how an MLLM should be integrated with a DiT for video generation by answering three questions: what intermediate representation should bridge the MLLM and DiT, how the MLLM should generate it, and how the DiT should incorporate it during diffusion rendering. Our analysis reveals three key findings: (1) discrete semantic visual tokens produced by an EMA-based tokenizer provide a stable and expressive interface, (2) autoregressive causal modeling is effective for generating these tokens, and (3) explicit visual-token conditioning is more effective than prompt refinement or latent bridging. Based on these findings, we propose BiVidGen, a hybrid framework where an MLLM first generates semantic visual tokens and a DiT renders videos conditioned on both text and these tokens via multi-layer cross-attention. Extensive experiments show that BiVidGen improves semantic alignment and temporal coherence over a fine-tuned DiT baseline, achieving stronger performance on VBench-Long. These results demonstrate that explicit MLLM-based visual planning provides an effective intermediate interface for text-to-video generation beyond text-only conditioning.

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想

提出**BiVidGen**混合框架，由MLLM首先生成语义视觉token，再由DiT以文本和这些token为条件，通过多层交叉注意力渲染视频。整体生成过程可表述为：MLLM从文本提示T生成中间表示D，DiT在(D, T)双条件下建模视频X。

### 2.2 关键技术细节

**（1）中间表示的选择——EMA离散语义视觉token**

- 比较了连续视觉特征与离散语义token，发现离散token更能与自回归生成对齐。
- 系统比较了5种量化方案：
  - (a) **EMA-based codebook**（论文最终选择）：指数移动平均更新码本，无梯度优化，无需额外监督，保持原始特征尺度，量化误差最低、熵最高、码本利用率高。
  - (b) Embedding codebook：基于梯度的向量量化目标 \( L_{VQ} = \sum_k \|sg[C_k]-D_k\|_2^2 + \beta\|C_k-sg[D_k]\|_2^2 \)。
  - (c) Embedding + MLLM理解损失：辅以冻结MLLM预测文本的交叉熵损失。
  - (d) Embedding + 解码器重建损失：辅以像素级重建损失。
  - (e) 层次化EMA（受Qwen3-VL启发）：对ViT多层特征分别量化，但实验表明对生成提升有限且增加训练不稳定性，故未采用。

**（2）MLLM生成机制——自回归因果建模**

- 比较了4种主流架构：因果注意力+离散token（最终选择）、双向注意力+离散token（掩码预测）、双向注意力+连续token（扩散损失）、因果注意力+流匹配头。
- 结果发现：在相同训练预算下，**离散token优于连续token**；**因果注意力在语义遵循上优于双向注意力**，且对视觉质量无显著影响。

**（3）MLLM-DiT融合策略——显式token + 多层交叉注意力**

- 比较了3类连接策略：
  - Prompt refinement（提示词精炼）：简单但信息限于语言空间，缺乏细粒度视觉信息。
  - Latent bridging（隐式潜在桥接）：可学习query提取MLLM隐状态，但存在信息瓶颈，且训练数据需求大。
  - **Explicit visual-token conditioning（显式视觉token条件，最终选择）**：通过交叉注意力将MLLM生成的视觉token注入DiT每个模块。
- DiT注入公式：\( X_{t}^{b+1} = X_{t}^{b} + \text{CrossAttn}(X_{t}^{b}, \text{Proj}(D)) \)，其中b为DiT模块索引。**多层跨层注入**（multi-layer cross-attention）使视觉引导贯穿整个去噪过程，效果最佳。

**（4）MLLM训练细节**

- 以Qwen3-VL-2B为基础模型，在文本-图像/文本-视频配对数据上微调。
- 在视觉token序列前添加分辨率-帧数前缀（resolution–frame prefix），以增强对分辨率和帧数的控制。
- 使用标准next-token prediction（teacher forcing），交叉熵损失仅应用于视觉token和`<eov>`标记。

**（5）DiT训练细节**

- 采用Wan-2.2-T2V-5B作为扩散主干，冻结主干参数，仅训练新增的交叉注意力模块和投影层（扩散MSE损失）。
- 保留原始3D RoPE位置编码以确保时空建模稳定。

### 2.3 推理流程

用户提示词 → MLLM自回归生成语义视觉token（从`<bov>`标记开始）→ 视觉token序列输入扩散生成器 → 输出最终视频。

## 6. 主要结论与发现

1. **EMA-based离散语义视觉token是MLLM与DiT之间的最佳接口**：具有最低量化误差（0.130）、最高熵（0.812）、高活跃率（0.841），比基于梯度更新的嵌入码本更稳定，能更好地保持原始特征分布。
2. **自回归因果建模是生成语义视觉token的有效机制**：离散token+因果注意力在VBench-Long上语义得分48.74，优于双向注意力的46.26，且与文本生成范式天然对齐。
3. **显式视觉token条件优于提示词精炼和隐式潜在桥接**：提示词精炼虽然能改善语义（60.74 vs 55.16），但信息限于文本空间；潜在桥接甚至明显差于DiT-only基线（语义仅32.58/35.23），表明隐状态条件分布与DiT期望不匹配。
4. **多层交叉注意力注入是最佳融合策略**：将视觉token注入每个DiT模块，显著提升语义分数（从48.74提升至76.25的语义得分，总分从72.79提升至80.77），且使DiT在减少采样步数时仍保持较好性能（30步仅降低0.91分）。
5. **方法具有可扩展性**：在1.3B和5B两种模型规模上均一致观察到MLLM语义规划的增益。

## 8. 不足与局限

### 8.1 实验覆盖方面

- **模型规模受限**：受资源约束，最大实验模型为5B DiT + 2B MLLM，无法验证在14B或更大规模上的表现；且对比方法如Sora、Veo-3为闭源系统，模型规模和数据不可比。
- **训练分辨率较低**：限于288×512、384×384、512×288，低于当前SOTA方法通常采用的更高分辨率，影响最终生成质量评估的上限。
- **数据规模差距**：训练数据量级（2M高质量视频）与SOTA方法的数据规模差距较大，限制了全面性能发挥。
- **无人工评估**：缺乏用户研究或人工偏好评估，仅依赖VBench-Long等自动指标，对生成质量的主观维度（如美学、自然度）覆盖不足。

### 8.2 方法层面的局限

- **层次化token结构未能提升生成性能**：虽然层次化token改善了重建（PSNR从13.71提升至16.02），但生成性能反而下降（总分从72.79降至72.54），说明引入多层级特征增加了MLLM预测难度和训练不稳定性。
- **附加监督信号无效或有害**：嵌入码本+LLM理解损失的组合性能最差（语义34.68、总分67.51），说明辅助监督可能干扰特征空间的一致性。
- **两阶段顺序生成的错误传播**：MLLM预测的token误差会直接传递给DiT渲染阶段，缺乏联合优化或纠错机制。
- **推理延迟增加**：虽然引入的MLLM规划步骤只增加了8秒延迟（45s vs 37s），但相比纯DiT方案仍有一定开销。

### 8.3 潜在偏差与社会风险

- **训练数据偏差**：训练数据来自多个开源数据集，可能存在内容分布偏差，影响生成内容的多样性和公平性。
- **误用风险**：更强的可控视频生成能力可能被用于制造虚假信息、深度伪造、版权侵权等恶意用途。论文在"更广泛影响"中也承认了这一风险。
- **评估基准偏差**：VBench-Long指标本身可能偏向某些风格或内容类型，单一benchmark可能无法全面反映真实视频生成质量。
