## 摘要
基于扩散的生成式视频压缩已成为一种有前景的范式，旨在提升感知质量，其中潜在帧需要被高效编码，同时作为去噪条件。然而，现有方法既未在潜在编码期间仔细设计引用与质量结构，也未考虑帧级质量变化对去噪过程的影响，这限制了编码效率并加剧了生成重建中的伪影传播。本文提出GVCHR，即基于层次引用的生成式视频压缩。关键思想是层次化地组织潜在帧，其中选定的高质量引用对潜在编码和生成重建均有益。在潜在编码中，GVCHR将层次引用结构与层次质量结构耦合，为更频繁被复用为引用的较低层帧分配更多比特。基于此设计，我们引入了层次时域上下文挖掘，利用互补的短期与长期时域上下文进行有效的潜在编码。在生成重建中，编码端层次被整合进层次注意力适配器中，该适配器附着于视频扩散Transformer。该适配器利用层次注意力限制每个潜在帧仅关注同层或更低层的引用，从而减少去噪过程中的伪影传播。实验在多个基准上验证了GVCHR。与先前最先进方法相比，GVCHR在LPIPS和DISTS指标上分别实现了50.5%和54.0%的BD-rate增益，同时带来明显改善的视觉质量。

## Abstract
Diffusion-based generative video compression has emerged as a promising paradigm to improve perceptual quality, where latent frames are required to be encoded efficiently while serving as denoising conditions. However, existing methods neither carefully design reference and quality structures during latent coding nor account for the impact of frame-level quality variation on denoising procedure, which limits coding efficiency and aggravates artifact propagation during generative reconstruction. In this paper, we propose GVCHR, Generative Video Compression based on Hierarchical Referencing. The key idea is to organize latent frames hierarchically, where the selected high-quality references benefit both latent coding and generative reconstruction. In latent coding, GVCHR couples a hierarchical reference structure with a hierarchical quality structure, assigning more bits to lower-layer frames that are reused more frequently as references. Built on this design, we introduce Hierarchical Temporal Context Mining to exploits complementary short- and long-term temporal context for effective latent coding. In generative reconstruction, the coding-side hierarchy is incorporated into a Hierarchical Attentive Adapter which is attached to a video diffusion transformer. This adapter uses hierarchical attention to restrict each latent frame to attend only to the same- or lower-layer references, thereby reducing artifact propagation during denoising. Experiments validate GVCHR on multiple benchmarks. Compared with the previous state-of-the-art method, GVCHR achieves 50.5% and 54.0% BD-rate gains in terms of LPIPS and DISTS, respectively, while also delivering clearly improved visual quality.

- **研究背景**：视频流量占据互联网主导地位，高效视频压缩对存储和传输至关重要。传统编解码器（如 HEVC、VVC）和大多数面向保真度的神经视频压缩（NVC）方法以 PSNR/MSE 等保真度指标为优化目标，在低码率下容易产生模糊和视觉伪影。
- **新兴方向**：生成式视频压缩（GVC）利用生成模型（特别是扩散模型）重建更真实、感知质量更高的细节；典型流程是先用 VAE 将视频编码为潜帧，再用学习到的潜编码器压缩，解码后在扩散模型引导下进行去噪重建。
- **现有问题**：
  - 现有扩散式 GVC 方法（DiffVC、GNVC-VD 等）未在潜编码阶段仔细设计**层级引用结构**和**层级质量结构**，通常采用简单的逐帧引用或未将参考角色与质量分配显式耦合。
  - 未考虑帧级质量变化对去噪过程的影响，低质量帧的伪影可能通过全注意力机制传播并放大，限制编码效率并加剧重建伪影。
- **核心问题**：如何在扩散式 GVC 中统一组织潜帧的引用关系与质量分配，使高质量参考帧既能提升编码效率，又能可靠地支撑生成式重建。
- **整体含义**：论文提出首个将层次化设计从潜编码端扩展到生成重建端的统一框架，验证了“层次引用+层次质量”策略在生成式视频压缩中的有效性。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
- 提出 **GVCHR（Generative Video Compression based on Hierarchical Referencing）**，将潜帧按引用重要性组织为多个层级：
  - **低层帧**：被更频繁复用为参考，分配更多比特、保持更高编码质量。
  - **高层帧**：编码更紧凑，不能作为低层的参考，降低错误累积与传播。
- 该层次结构在编码端用于高效潜编码，在生成端通过层次注意力限制参考范围，减少去噪时的伪影传播。

### 2.2 整体框架
- 输入视频先分离为关键帧（保留颜色）和灰度中间帧（颜色信息由生成阶段恢复），经 3D VAE 编码得到潜帧 \(\{x_t\}\)。
- 潜编码器采用基于条件编码框架（DCVC-RT），并引入 **Hierarchical Temporal Context Mining (HTCM)** 提取上下文。
- 生成重建阶段，解码后的潜帧 \(\{ \hat{x}_t \}\) 和特征 \(\{ \hat{f}_t \}\) 通过 **Hierarchical Attentive Adapter (HA-Adapter)** 注入视频 DiT，采用流匹配（flow matching）进行去噪。

### 2.3 层次化潜编码
- **层级结构**：GOP 大小为 32（对应潜 GOP 8），每个潜 mini-GOP 为 4 帧，采用三层设置（最优），权重模式 \([0.5, 0.9, 0.5, 1.2]\)，对应层 ID \(\{2, 1, 2, 0\}\)。关键帧权重 \(w_0=8.0\)。
- **编码流程**：
  \[
  y_t = g_a(x_t | c_t), \quad \hat{y}_t = \lfloor y_t \rceil, \quad \hat{x}_t, \hat{f}_t = g_s(\hat{y}_t | c_t)
  \]
  \[
  \mu, \sigma = g_{ep}(y_t | c_t^e), \quad c_t, c_t^e = HTCM(\hat{f}_{<t})
  \]
  其中 \(c_t\) 用于条件编解码，\(c_t^e\) 用于熵模型参数估计。

### 2.4 层次时域上下文挖掘（HTCM）
- **短期上下文**：取最近的一个同层或低层已解码帧的特征作为 \(\hat{f}_s\)，提供局部细节。
- **长期上下文**：所有之前已解码的**最低层（Layer 0）**帧，通过门控槽注意力（GSA）更新固定大小的长期记忆，得到的表示 \(m_l\) 代表全局时域语义。
- 长期上下文获得方式：用短期上下文 \(c_t^S\) 作为 Query，对长期记忆 \(m_l\) 做交叉注意力，得到 \(c_t^L\)。
- 两者经上下文精炼网络融合，输出 \(c_t\) 和 \(c_t^e\)。
- 其中引入**元嵌入** \(e_l = Linear(SiLU(Linear([L_l, l, qp_l])))\) 编码层级、帧索引和量化参数信息。

### 2.5 层次注意力适配器（HA-Adapter）
- 解码后的潜帧与特征拼接后 patchify 成帧级 token \(\{\hat{x}'_t\}\)。
- 用**层次注意力掩码**替代原有全注意力，控制参考范围：
  \[
  o = \text{softmax}\left(\frac{qk^\top}{\sqrt{d}} + M\right) v
  \]
  \[
  M_{i,j} = \begin{cases}
  -\infty & \text{if } L_i < L_j \\
  0 & \text{if } L_i \ge L_j
  \end{cases}
  \]
  即帧 \(i\) 只能关注层 ID 不高于自己的帧 \(j\)（同层或低层）。
- 该设计避免低质量高层帧的伪影污染高质量低层帧，同时利用块注意力加速计算。

### 2.6 训练损失与多阶段训练
- 率失真损失：\(L_{RD} = R + \lambda D\)，其中 \(D\) 在不同阶段取值不同：
  - **潜保真损失**：\(L_{Codec} = \frac{1}{1+T/4} \sum_t w_t \cdot d_{MSE}(x_t, \hat{x}_t)\)
  - **条件流匹配损失**：\(L_{CFM} = \mathbb{E} \|\hat{\epsilon}(z_\tau, \tau, u) - (z_N - z_0)\|_2^2 / ...\)
  - **像素域重建损失** \(L_{Rec}\) 和 **感知损失** \(L_{LPIPS}\)。
- 采用六阶段训练：前三个阶段只训练潜编码器并逐步增加帧数（5→17→33）；第四阶段联合优化编码器与 HA-Adapter 并用流匹配损失；第五阶段引入像素重建和感知损失，使用五个 λ 值训练五种质量等级；第六阶段高分辨率微调。
