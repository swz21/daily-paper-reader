## 摘要
生成混合类型的表格数据需要联合建模多样的特征分布及其复杂的跨列依赖关系。变分流匹配通过因子化分布处理不同的端点，但在共享骨干网络中，特征特定的处理和跨列交互仍然隐式进行。我们引入了基于特征统一专业化与跨列交换（FUSE）的方法，以明确分离这些角色。FUSE对数值特征和类别特征分别应用自适应混合模块，使每个特征能够组合共享的专业子网络，同时联合注意力机制保持所有列之间的信息交换。我们还刻画了受限条件上下文带来的超额总体风险，并通过端点预测风险界定了连续Wasserstein生成误差。在八个表格数据集上的综合实验表明，FUSE在分布保真度和下游实用性指标上均取得了强大且一致的表现。

## Abstract
Generating mixed-type tabular data requires jointly modeling diverse feature distributions and their complex cross-column dependencies. Variational flow matching handles distinct endpoints via factorized distributions, yet leaves feature-specific processing and cross-column interactions implicit within a shared backbone. We introduce Feature-wise Unified Specialization with cross-column Exchange (FUSE) to explicitly separate these roles. FUSE applies separate adaptive mixture modules to numerical and categorical features, allowing each feature to combine shared specialized subnetworks, while joint attention preserves information exchange across all columns. We also characterize the excess population risk from restricted conditioning contexts and bound the continuous Wasserstein generation error by endpoint-prediction risk. Comprehensive experiments on eight tabular datasets demonstrate that FUSE achieves strong and consistent performance across distributional fidelity and downstream utility metrics.

## 2. 论文提出的方法论

### 2.1 核心思想

- FUSE 将变分流匹配中的端点预测网络设计为**类型自适应混合处理 + 联合注意力**的交替堆叠结构。
- 每个特征类型（数值/类别）拥有独立的**自适应混合模块**，通过共享的专用子网络组合，使不同特征得到不同的变换；
- 随后通过**联合多头自注意力**在所有列之间交换信息，实现跨类型上下文建模。

### 2.2 关键技术细节

- **输入表示**：  
  数值特征和类别特征分别经过线性层/嵌入层得到 token 矩阵 \(H_{num}, H_{cat} \in \mathbb{R}^{n \times d_h}\)，并加入时间嵌入 \(\psi(t)\)。

- **自适应混合模块**（对应 Soft MoE 的 aggregate-transform-recombine 流程）：
  1. 计算对齐分数 \(R = H \Phi / \sqrt{d_h}\)；
  2. 沿特征轴做 softmax 得到聚合权重 \(D\)，沿组件轴做 softmax 得到重组权重 \(C\)；
  3. 聚合：\(U = D^\top H\)，得到 \(S_r\) 个潜在组件；
  4. 每个组件由共享的专用子网络 \(g\) 处理：\(V_s = g_{\kappa(s)}(U_s)\)；
  5. 重组：\(\tilde{H} = H + C V\)，形成残差更新。

- **联合注意力**：  
  将数值和类别 token 拼接后，进行多头自注意力（无掩码），实现全列交互；输出再切分为数值/类别 token 进入下一层。

- **端点预测**：  
  最后一层 token 经特征特定 head 输出数值均值 \(\mu_{\theta,j,t}(x)\) 和类别概率 \(\pi_{\theta,k,t}(x)\)，对应因子化端点分布（高斯/类别分布），训练损失为端点负对数似然（式 3）。

- **理论部分**：
  - **命题 1**：若将条件 σ-代数从完整 \(F\) 限制为 \(G\)，端点风险增量等于数值后验均值的 \(L^2\) 距离除以 \(2\nu_t\) 加上各类别 KL 散度之和，显式刻画了**受限条件上下文带来的超额总体风险**。
  - **架构瓶颈分析**：通过两个构造性示例，证明仅靠共享单一表示会带来不可消除的误差，而特征相关的重组权重和联合注意力可以消除或避免这种瓶颈。
