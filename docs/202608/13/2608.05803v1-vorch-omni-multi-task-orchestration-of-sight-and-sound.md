## 摘要
近期生成式视频建模的进展已实现多样化的生成、基于参考的合成、扩展和编辑，但现有方法往往依赖碎片化的任务特定模型。通用模型必须区分异构的目标、源和参考信号，以确定生成、保留或用作指导的内容，同时减少任务间的干扰。联合音视频生成通过跨模态引入多样化的条件设置和输出配置，进一步增加了这一挑战。我们提出Vorch-Omni，一个基于任意条件到任意输出公式的统一多任务音视频合成框架。它灵活地将视频和音频信号视为条件输入或生成目标。令牌级条件掩码和任务标识符区分目标、源内容和参考，而位置类型将时间上下文与独立条件分离。为捕捉语义和结构信息，Vorch-Omni采用互补的视觉条件路径：视觉语言模型结合文本指令解释采样帧，视频VAE将条件编码为潜在令牌以提供直接指导。我们进一步构建分布式数据管道，以策划多样化的时间对齐音视频片段，生成结构化字幕和元数据，并平衡异构任务分布。基于单一的流匹配扩散变换器，无需特定任务架构更改，Vorch-Omni支持超过10项任务，包括文本到视频、文本到音视频、图像和参考条件生成、时间扩展、音频驱动生成、视频转换以及音视频编辑。该统一框架为通用音视频生成与操作提供了可扩展的基础。

## Abstract
Recent advances in generative video modeling have enabled diverse generation, reference-based synthesis, extension, and editing, but existing approaches often rely on fragmented task-specific models. A general model must distinguish heterogeneous target, source, and reference signals to determine what to generate, preserve, or use as guidance, while reducing interference among tasks. Joint audio-visual generation further increases this challenge by introducing diverse conditioning and output configurations across modalities. We present Vorch-Omni, a unified multi-task framework for audio-visual synthesis based on an arbitrary-condition-to-arbitrary-output formulation. It flexibly treats video and audio signals as either conditioning inputs or generation targets. Token-level conditioning masks and task identifiers distinguish targets, source content, and references, while position types separate temporal context from independent conditions. To capture semantic and structural information, Vorch-Omni employs complementary visual conditioning pathways: a vision-language model interprets sampled frames with text instructions, and a video VAE encodes conditions into latent tokens for direct guidance. We further build a distributed data pipeline to curate diverse temporally aligned audio-visual clips, generate structured captions and metadata, and balance heterogeneous task distributions. Built on a single flow-matching diffusion transformer without task-specific architectural changes, Vorch-Omni supports over 10 tasks, including text-to-video, text-to-audio-video, image- and reference-conditioned generation, temporal extension, audio-driven generation, video transformation, and audio-visual editing. This unified framework provides a scalable foundation for general-purpose audio-visual generation and manipulation.

- **核心问题**：当音视频协同参与生成时，一个通用模型需要回答一个关键问题——在目标视频、源视频、一个或多个参考信号同时存在的输入中，**什么需要生成、什么需要保留、什么仅作身份/结构/风格参考**。传统的任务定义无法刻画这种异构角色的组合；且引入音频后，输入输出配置的空间以跨模态方式进一步扩大（如视频可驱动音频、音频也可驱动视频、二者可同时生成、可互为条件）。
- **整体含义**：论文旨在回答一个更广泛的研究问题：**能否设计一个可复现且可扩展的任务界面，不仅覆盖多样化的视觉任务，还支持音频和视频条件和输出的任意组合**，从而用单一模型统一处理生成、引用、扩展、编辑等任务，而不是为每个任务单独构造专用结构。

## 2. 论文提出的方法论

### 2.1 核心思想

- **统一任务公式**：将所有任务视为"任意条件到任意输出"（arbitrary-condition-to-arbitrary-output）的条件流匹配问题。任务用四元组表示：T = (Xv, Cv, Xa, Ca)，即视频目标、视频条件、音频目标、音频条件。任意列表可为空，由此同一公式可覆盖文本到视频、文本到音视频、跨模态生成、时间扩展、参考条件生成、转换和编辑等任务类型。
- **任务与骨干分离**：任务配置只负责确定"谁是干净条件、谁是被去噪目标、如何定位"，由同一个共享的流匹配音频-视频变换器统一处理后端计算。新增任务只需改变配置而不是网络架构。

### 2.2 关键技术细节

- **流匹配框架**：对每个目标信号按 x_σ = (1−σ)x₀ + σz 构造插值，定义速度场 u = z − x₀。视频和音频共享一个噪声水平 σ，但各自使用独立的高斯噪声。
- **角色感知序列构造**：
  - **条件掩码（Conditioning Mask）**：每个 token 有 m_i ∈ {0,1}，1 表示干净条件，0 表示去噪目标；对应扩散时间 τ = 0 或 τ = σ，明确告知模型哪些 token 应保持不变、哪些需要去噪。
  - **任务标识符（Task Identifiers）**：每个 token 关联一个任务 ID r，通过可学习嵌入 E(r) 注入；ID 0 为默认目标/普通条件，非零 ID 表示主体参考、帧参考、音频参考、编辑、转换、动画、相机控制等角色，使内容相同但功能不同的 token 被正确区分。
  - **位置类型（Position Types）**：四种取值（-1 独立参考、0 目标前上下文、1 目标区间、2 目标后上下文），p ≥ 0 的条目合并到连续时间轴，p = −1 的条目使用独立位置网格，防止独立参考被误读为时间相邻片段。
- **互补的视觉条件路径**：
  - **VLM 语义路径**：以 1 FPS 采样条件帧，与用户指令和任务模板拼接，由视觉语言模型（Gemma 等）联合解释，输出高层语义上下文并投射到视频和音频两个条件空间。
  - **VAE 潜在路径**：视频 VAE 将完整视觉条件编码为干净的时空潜在 token，保留身份、纹理、布局和运动细节。
  - 两条路径互补：VLM 处理高阶语义跟随，VAE 保留细粒度结构保真。
- **音频-视频流变换器骨干**：基于 LTX-2.3 的 48 层双流骨干，视频流 32 头×头维 128，音频流 32 头×头维 64（不对称容量分配）。每块含 AdaLN 自注意力、文本交叉注意力、双向门控交叉注意力（音频→视频 + 视频→音频）和独立 FFN；某模态缺失时跳过其计算，模型自然退化为单模态。
- **训练目标**：仅对目标 token 计算速度场损失 L = Lv + La，按目标 token 占比归一化；所有任务共享同一目标函数，在数据加载器层面通过加权多任务采样平衡。
- **推理**：与训练一致的配置转换、ODE 积分、VAE 解码；输出模态由目标列表决定。

## 6. 论文的主要结论与发现

- **统一公式有效**：单一流匹配变换器配合角色感知的序列构造，可以在不修改架构的前提下覆盖 10 余类任务，实现跨任务共享参数并降低任务间干扰。
- **总体平等与局部优势并存**：
  - 81.4% 的维度级判断为平局，整体净胜率 −1.9%；
  - 在**音频提示跟随（+7.1%）、参考对齐（+6.6%）、音视频同步（+5.9%）和音频质量（+3.3%）**方面获得正向净胜率；
  - 音频驱动任务的总净胜率 +3.5%，其音视频同步维度净胜率高达 +24.3%（唇音同步维度达 +45.6%）；
  - 动画与替换（+2.0%）、视频转换（+1.9%）、视频编辑（+1.2%）和相机控制（+0.7%）等任务也有正向优势。
- **结论**：Vorch-Omni 的优势集中在**跨模态协调和参考信息保留**等统一模型特有的能力维度上，说明显式的条件角色标注为扩展异构音视频任务提供了可行路径。

## 7. 优点

- **统一任务表达能力强**：任意条件到任意输出公式以简洁四元组 + 掩码 + 任务 ID + 位置类型统一了 10 余类任务，可扩展性和通用性高。
- **角色-位置分解设计精巧**：将"语义角色"与"时间关系"正交化，内容相同但用途不同的信号可以被明确区分，减少任务间干扰。
- **互补条件路径兼顾语义与保真**：VLM 通道负责高层指令理解和引用语义，VAE 潜在通道保留细粒度结构信息，定性示例（如角色替换后的身份与服饰保真）显示两者协同有效。
- **数据管线工业化程度高**：分布式、版本化的数据管道包含镜头切分、质量过滤、去重、结构化字幕、音频元数据和任务打包，支持任务配置的灵活实例化与加权混合采样。
- **评估维度专业化**：GSB 三值判断与多维度分层评价框架兼顾了整体偏好和模态协调等细粒度指标，能捕捉到统一模型相对基线的差异化优势。
