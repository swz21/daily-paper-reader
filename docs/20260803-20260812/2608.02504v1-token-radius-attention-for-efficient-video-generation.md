## 摘要
视频扩散变换器（VDiTs）能够实现高保真生成，但密集的3D自注意力带来了二次方成本。现有的头部级和块级稀疏方法在查询之间共享计算预算，忽略了特定于令牌的注意力需求。我们观察到，保留密度在不同查询间存在差异，但与注意力熵呈对数线性相关，而主导交互形成以查询为中心、半径依赖于令牌的邻域。基于这些发现，我们提出了令牌半径注意力（TRA），一种无需训练框架，将查询熵映射到解析令牌预算，并将其转换为时间衰减半径，无需显式键排序。融合熵提取、预热重用和块稀疏掩码构建进一步减少了开销。在七种Wan2.1、Wan2.2和HunyuanVideo T2V/I2V配置中，TRA仅保留9-19%的注意力交互，实现了1.56倍至2.05倍的加速，并保持具有竞争力的生成质量。代码可在https://github.com/IF-LAB-PKU/Token-Radius-Attention获取。

## Abstract
Video Diffusion Transformers (VDiTs) enable high-fidelity generation but incur quadratic cost from dense 3D self-attention. Existing head- and block-level sparse methods share computation budgets across queries, overlooking token-specific attention demand. We observe that retained density varies across queries yet correlates log-linearly with attention entropy, while dominant interactions form query-centered neighborhoods with token-dependent radii. Based on these findings, we propose Token Radius Attention (TRA), a training-free framework that maps query entropy to an analytic token budget and converts it into a temporally decayed radius without explicit key ranking. Fused entropy extraction, warm-up reuse, and block-sparse mask construction further reduce overhead. Across seven Wan2.1, Wan2.2, and HunyuanVideo T2V/I2V configurations, TRA retains only 9-19% of attention interactions and achieves 1.56x-2.05x speedup with competitive generation quality. Code is available at https://github.com/IF-LAB-PKU/Token-Radius-Attention.

# Token Radius Attention for Efficient Video Generation 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

视频扩散变换器（VDiTs）是当前高保真视频生成的主流架构，但其核心的3D稠密自注意力机制带来**O(N²)** 的二次方计算复杂度，成为视频生成在分辨率、时长和部署规模上的主要瓶颈。

- **已有稀疏化方法的不足**：现有稀疏注意力方法主要分为两类：
  - **头部级（Head-level）**：如 SVG、Radial Attention、Sparse-vDiT，为整个注意力头分配固定的空间/时间模式；
  - **块级（Block-level）**：如 SpargeAttn、SVG2、SVOO，选择重要的 query–key 块对。
  
  这两类方法都**在多个查询之间共享同一计算预算**（如统一保留密度、统一半径调度、统一键块集合），但自注意力本质上是**按查询（query）逐行独立归一化**的，不同查询的注意力集中/分散程度差异极大。共享预算会导致：
  - 对注意力集中的查询浪费计算；
  - 对注意力扩散的查询遗漏关键键（key），从而损害生成质量。

本文的核心主张是：**稀疏分配应以 token 为最小粒度，同时保持结构化掩码以支持高效执行**，以解决“自适应性与执行效率之间的张力”。为此提出 **Token Radius Attention (TRA)**——一种无需训练（training-free）的框架，将查询级注意力熵映射为 token 级计算预算，再转化为时间衰减的二维空间半径，从而在保留 token 级自适应性的同时，获得规则、可高效执行的稀疏掩码。

## 2. 方法论：核心思想与关键技术细节

### 2.1 两大观察洞见（Insight）

- **Insight I：Token 级注意力稀疏性**
  - 对于目标注意力质量 τ，定义保留密度 \(B_i^\tau = K_i^\tau / N\)（\(K_i^\tau\) 为达到质量 τ 所需的最小 top-k 键数）。
  - 实验发现：同一层同一头内的不同查询，其保留密度可相差**数量级**；且 **\(\log B_i^\tau\) 与注意力熵 \(H_i\) 近似线性关系**（R² = 0.940–0.966），说明熵可以作为查询级预算的紧凑、免训练的信号。

- **Insight II：令牌半径注意力模式**
  - 高注意力键围绕查询形成**近似圆形邻域**，但半径因 token、头、层而异；
  - 归一化注意力概率随二维空间距离**近似指数衰减**（R² ≈ 0.791–0.994），因此半径可以作为单调结构化的支持参数，无需对任意键进行排序。

### 2.2 熵到预算映射（Entropy-to-Budget Mapping）

- 采用“熵等效支持”近似：假设一个均匀分布在 \(m_i\) 个键上的等效分布，使其熵等于真实注意力的熵，得到 \(m_i = \exp(H_i)\)。
- 目标质量 τ 下的预测键数量：
  \[
  \hat{K}_i^\tau = \lceil \tau \exp(H_i) \rceil
  \]
- 预测保留密度：
  \[
  \hat{B}_i^\tau \approx \frac{\tau \exp(H_i)}{N}
  \]
- 该映射为解析、单调、无参数，且与实测趋势一致；附录中还验证了 Lognormal、Gamma、Weibull 等参数化分布下的熵-预算映射，但 uniform 近似因闭式、无参数而被保留。

### 2.3 预算到半径掩码构建（Budget-to-Radius Mask Construction）

- **时间衰减半径模型**：空间半径随帧间时间距离按指数衰减：
  \[
  \phi(\delta) = \exp(-\gamma \delta)
  \]
  查询 i 在目标帧 t 的半径为 \( r_{i,t} = r_i \phi(|t - f_i|)\)。
- **预算匹配半径**：通过连续面积近似和离散格点精确计数，找到最小的候选半径 \(r_i\)，使得按半径掩码保留的键数达到或超过预测预算 \(\hat{K}_i^\tau\)：
  \[
  r_i = \min\{r \in \mathcal{R} : C_{grid}^i(r) \ge \hat{K}_i^\tau\}
  \]
- **Token 半径掩码定义**：
  \[
  M_{ij} = \mathbb{I}[d_s(i,j) \le r_i \phi(|f_j - f_i|)]
  \]
  TRA 在数学上等价于对注意力打分加入 \(-∞\) 掩码（仅对视频键部分应用，文本键保持稠密）。

### 2.4 高效实现：定制内核与布局

- **Flash Radius Mask 内核**：
  - 将每帧划分为空间 tile，按 tile-major 顺序重排 token，使相邻 token 在序列上连续，从而将 token 级掩码聚合成更少的稠密块；
  - 融合距离计算、半径比较、块剪枝、token 投票，一步生成所有头的块稀疏掩码，交给 FlashInfer 执行；
  - 利用空间边界框预筛除不可能包含有效交互的块对，降低逻辑复杂度。
- **融合注意力熵内核**：
  - 利用公式 \(H_i = \log Z_i - \sum_j p_{ij} s_{ij}\) 在在线 softmax 过程中累积熵，无需物化完整注意力矩阵；
  - 仅在前 25% 去噪步（稠密预热阶段）提取熵，后续稀疏步骤直接**复用**预算、半径和掩码（基于跨步熵稳定性实验，最小余弦相似度 0.945）。

## 6. 主要结论与发现

1. **注意力需求是 token 特异性的**：保留密度随查询变化可达数量级差异，且与熵呈对数线性相关，验证了共享预算的不可靠性。
2. **主导交互呈查询中心的半径模式**：高注意力键围绕查询形成近似圆形邻域，注意力概率随空间距离指数衰减——支持将预算转为半径。
3. **TRA 实现高效且保真**：
   - 在 7 个配置上，TRA 的 VBench Overall 得分均为稀疏方法中最佳，且接近稠密注意力；
   - 仅保留 9%–19% 的注意力交互，FLOPs 显著低于对比方法；
   - 端到端加速比达 **1.56×–2.05×**（HunyuanVideo 上最高 2.05×）；
   - 定制内核大幅降低辅助开销：Flash Radius Mask 比朴素实现快 10.35×，Fused Entropy 快 12.34×。
4. **跨模型泛化性**：熵-预算关系和半径注意力模式在 HunyuanVideo 上同样成立（R² = 0.978–0.993）。
5. **工程可用性**：通过 warm-up 重用和查表式半径选择，训练无关的 TRA 可直接部署于现有扩散流水线。

## 8. 不足与局限

- **稀疏模式受限**：TRA 仅支持基于距离的固定时间衰减模式，无法捕获内容自适应的长程交互（如跨镜头的物体对应、非局部运动、场景语义关联），可能在某些动态复杂场景下丢失关键注意力依赖。
- **依赖块稀疏后端开销**：由于没有专用 token 级稀疏内核，仍通过块稀疏 FlashInfer 执行，块内存在冗余计算；作者也在 Limitation 中承认了这一点，并指出未来可设计融合 token 收集与稀疏注意力的专用内核。
- **Radial 对比设置不公平**：Radial Attention 模型设置较低分辨率、较少帧数，其加速比和 VBench 分数可能被低估，影响对比结论的严谨性。
- **缺乏超参自动调整**：时间衰减系数 γ（Wan 用 0.6、HunyuanVideo 用 0.95）、目标质量 τ、预热比例等均需人工设定，未提供自动选择方法，跨模型迁移需要调参。
- **未验证极端场景**：更高分辨率、更长时间视频（如分钟级）或训练后微调结合的效果未知；未与可训练稀疏注意力方法对比，无法判断在可学习条件下的相对优劣。
- **指标局限**：依赖 VBench 自动指标，未包含人类评估；未报告生成视频的多样性和分布外风险（如少样本主题退化）。
- **算力细节缺失**：未说明总推理时间、各配置的重复实验次数、标准差等统计信息，削弱了结果的定量可复现性。
